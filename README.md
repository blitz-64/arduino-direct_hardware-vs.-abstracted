# arduino-direct_hardware-vs.-abstracted
Two simple programs to learn different ways for the programming function on an Arduino Nano. The Nano is connected to 2 buttons, 2 LEDs, a piezo buzzer, and a joystick. Both programs light up either LED when their respective button is pressed.
The microcontroller used on the Arduino Nano is the ATmega328P. Datasheet: https://ww1.microchip.com/downloads/en/DeviceDoc/Atmel-7810-Automotive-Microcontrollers-ATmega328P_Datasheet.pdf.

This small project was done to learn about direct hardware programming on a microcontroller using interrupts and bitwise operations rather than a continuous loop.
