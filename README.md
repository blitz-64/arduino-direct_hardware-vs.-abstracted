# arduino-direct_hardware-vs.-abstracted
simple program comparison for the same function on an arduino nano board. The board is connected to 2 buttons, 2 LEDs, a piezo buzzer, and a joystick.
The microcontroller used on the arduino nano is the ATmega328P; https://ww1.microchip.com/downloads/en/DeviceDoc/Atmel-7810-Automotive-Microcontrollers-ATmega328P_Datasheet.pdf.
